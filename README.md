# AnswerSearch

> 让散落在表格里的知识，随搜随得。

AnswerSearch 是一个面向题库、问答库、知识库和普通 Excel 数据表的纯静态检索系统。无需后端、无需数据库、无需账号体系，上传文件后即可在浏览器中完成智能解析、本地缓存和快速搜索。

适合个人资料检索、内部知识查询、考试题库搜索、产品资料查找、客服问答库和轻量级知识管理等场景。

## 核心特性

- 支持上传 `.xlsx`、`.xls`、`.csv`
- 支持同时管理多个资料库
- 自动读取 Excel 内的全部工作表
- 自动识别单列、两列、标准题库和任意多列表格
- 无固定表头要求，陌生字段也不会被丢弃
- 所有非空字段均可参与检索
- 支持题干、答案、选项、解析及自定义字段搜索
- 支持中文与拼音搜索
- 支持多关键词组合查询
- 搜索结果实时高亮
- 只展示命中的内容
- 支持选择题、问答题和知识条目展示
- 使用 IndexedDB 自动缓存资料库
- 刷新页面或下次打开无需重新上传
- 支持 `/` 快捷键快速聚焦搜索框
- 支持 PC 与手机端响应式布局
- 纯静态运行，文件不会上传到服务器

## 智能解析能力

AnswerSearch 不要求 Excel 必须按照固定模板整理。

### 标准题库

可识别常见字段：

- 类型 / 题型
- 题干 / 题目 / 问题
- 选项 A～F
- 答案 / 正确答案 / 参考答案
- 解析 / 说明 / 答案解析

存在选项时会自动识别为选择题，否则按问答题或知识条目展示。

### 两列表格

例如：

| 问题 | 答案 |
|---|---|
| EdgeOne Pages 是什么？ | 一个适合部署静态站点的边缘开发平台。 |

系统会自动将第一列作为标题或问题，第二列作为内容或答案。

### 单列表格

每一个非空单元格都会被识别为一条可检索知识内容。

### 任意多列表格

对于产品资料、客户信息、制度文档、知识清单等普通数据表，系统会保留每一列的字段名称和字段内容，并将所有字段加入检索范围。

### 无表头或陌生表头

系统会结合第一行内容和数据结构自动判断是否存在表头。即使列名不在预设范围内，也会完整保留并展示数据。

## 搜索方式

### 普通关键词

输入任意中文内容即可搜索所有字段。

```text
北京
```

### 拼音搜索

中文内容支持无声调拼音检索。

```text
beijing
```

### 多关键词搜索

多个关键词使用空格分隔，只有全部关键词都命中的记录才会展示。

```text
北京 首都
```

### 快捷键

在页面中按下 `/`，可以快速聚焦搜索框。

## 数据与隐私

所有 Excel 和 CSV 文件均在浏览器本地解析，不会上传到服务器。

解析后的资料库通过 IndexedDB 保存到当前浏览器：

- 刷新页面后仍然保留
- 再次打开站点无需重新上传
- 不同浏览器或不同设备之间不会自动同步
- 清除浏览器站点数据后，本地资料库会被删除

因此，AnswerSearch 很适合存放个人资料和内部知识，但仍建议不要在公共设备上导入敏感文件。

## 技术实现

- HTML
- CSS
- 原生 JavaScript
- SheetJS：Excel / CSV 解析
- pinyin-pro：中文拼音检索
- IndexedDB：浏览器本地资料库缓存

项目没有使用 React、Vue、Node.js 或构建工具。

## 本地运行

由于项目是纯静态站点，可以直接打开 `index.html`。

为了获得更稳定的浏览器行为，也可以使用任意静态服务器运行，例如：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 部署到 EdgeOne Pages

1. 在 EdgeOne Pages 创建新项目。
2. 关联本 GitHub 仓库。
3. 框架选择“其他”或“静态站点”。
4. 构建命令留空。
5. 根目录保持默认。
6. 输出目录填写 `/` 或使用项目根目录。
7. 保存并部署。

项目不需要配置环境变量，也不依赖服务端函数。
